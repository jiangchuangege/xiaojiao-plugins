# xiaojiao-plugins
# 🐱 小焦 (XiaoJiao) 社区插件仓库

欢迎来到**小焦 AI 助手**的插件宝库！  
这里汇集了由社区贡献的各类扩展插件，让你的小焦更聪明、更强大。

小焦支持 **四种插件类型**，你可以根据自己的需求灵活选择：

| 类型 | 说明 |
| :--- | :--- |
| 🐍 **Python 插件** | 最灵活，可调用任意 Python 库，适合复杂逻辑 |
| 🟢 **Node.js 插件** | 使用 JavaScript，适合前端生态或 npm 包 |
| 🌐 **API 插件** | 通过 JSON 配置即可接入任何 HTTP 接口 |
| 🧠 **Skill 插件** | 将知识或指令注入小焦的人设，改变回答风格 |

---

## 🚀 快速开始

### 安装插件
1. 将本仓库中的插件目录复制到小焦的 `plugins/` 文件夹下。
2. 或者，使用小焦自带的插件管理功能（如果有）直接安装。

### 启用/禁用插件
在小焦的 `xiaojiao_control.json` 中调整插件的 `enabled` 字段，即可控制是否加载。

## 🤝 如何贡献

我们非常欢迎你的加入！无论你是想分享自己写的插件，还是修复现有插件的 bug，都请按以下流程：

1. Fork 本仓库。
2. 在 `plugins/community/` 下新建你的插件目录（命名清晰即可）。
3. 确保包含 `plugin.json` 元数据文件和入口文件（参考 [模板](./templates)）。
4. 提交 Pull Request，并简要说明插件功能。
5. 维护者审核通过后，可能会移至 `official/` 目录。

> 详细开发指南请参阅 [docs/plugin_development.md](./docs/plugin_development.md)（待完善）
